## 未完了・未検証

- GitHub Pagesの初回有効化、非公開データリポジトリの作成、サーバー秘密情報の設定、実サービスとの同期・別端末復元。
- 誤認識しやすいスキャン・手書き・教材境界を含む外部AI/OCR解析の精度評価。
- Androidタブレット・スマートフォン、Windowsの実機・支援技術、320px相当・200%文字拡大の実ブラウザ評価。
- 同期競合の自動マージは未実装。ローカルZIPを保持してから、リモート復元で解決します。
- 同期APIはリクエストサイズ・転送件数を制限します。大量のデータは一括同期に収まらない場合があります。Cloudflare FreeのCPU制限10ms・サブリクエスト50回にも影響されるため、大きなPDFでの本番運用は未検証です。有料プランへ勝手に切り替える処理はありません。
- シリーズ同一性の自動確定は、類似度だけでは行いません。曖昧な場合は手動確認が必要です。

## 利用者の実機確認

まず架空PDFか個人情報のない少量のPDFで、追加→確認トレイ→分類保存→閲覧→書き出し→ZIPバックアップを確認してください。画像PDFではOCR後に文字と分類が正しいか確認してください。GitHub未接続の間は、ブラウザのデータ削除前にZIPバックアップが必要です。
