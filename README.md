# Schoolmanager — プリントライブラリ

公開アプリ: https://totoro0419.github.io/schoolmanager/

PDFの学習プリントを、教科・分野・単元・シリーズで管理する日本語Webアプリです。React / TypeScript / Vite / IndexedDB / PDF.js / pdf-libで実装しています。

**現在は端末内保存で利用できます。非公開GitHub保存は同期APIとデータリポジトリが未接続です。すべての完了条件を満たした完成版とはしていません。**

## 使える機能

- 正式な13教科、動的な分野・単元・教材タイプ・シリーズ・タグの追加、別名の照合、承認・統合
- 複数PDFの取り込み、進捗、個別の失敗・再試行、SHA-256による重複検出
- 通常のPDFと埋込JSON付きPDFの両方に対応。破損したメタデータは警告して本文を受け入れる
- 印刷された教科名の照合、矛盾の検出、項目別の確定・仮分類・未分類、ユーザー確定の保護
- 独立した外部AI解析用プロンプト、JSON Schema、現在の分類辞書・解析用JSONの出力、AI結果の再検証
- 端末上での日本語・英語OCR（初回は認識エンジン・言語データの取得に通信が必要）
- PDF閲覧、拡大縮小、ページ移動・回転、原本とメタデータ付き整理版のダウンロード
- 分野・単元・シリーズ・教材番号・表示順・タグ・関連教材の編集、変更履歴の復元
- ページの並べ替え・除外・回転、印刷番号、白紙・重複候補、手書き注釈、範囲指定での教材分割
- タイトル・分類・別名・番号・認識済み本文のローカル検索、絞り込み、並び替え、お気に入り、一括教科変更
- 原本・整理版・辞書・履歴を含むZIPバックアップと検証付き復元、復元できるゴミ箱
- PWA用マニフェスト、アプリ資材のオフラインキャッシュ、保存領域の保持要求
- サーバーに秘密情報を分離するGitHub同期API、非公開判定、ハッシュ検証、競合検出、原子的なコミット（実サービスへの接続は未実施）

## 起動

Node.js 24を推奨します。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

テスト用PDFは `npm run fixtures` で生成できます。実在の学校プリントは必要ありません。生成物はGitの対象外です。

## GitHub Pages

公開先: https://totoro0419.github.io/schoolmanager/

ロゴは、折り重ねたプリントで「S」を表現しています。アプリ内、ブラウザのアイコン、ホーム画面用アイコンに共通して使用します。

初回のみ、リポジトリの **Settings → Pages → Source: GitHub Actions** を設定してください。その後、Actionsの `Verify and publish Schoolmanager` を再実行します。自動テスト、ビルド、公開ファイル検査の後にデプロイします。未有効化の場合はビルドだけが通り、デプロイはスキップされます。

公開リポジトリ・Pages成果物へ学校のPDF・個人情報・トークンを入れないことをCIでも検査します。PDFはアプリを使った端末のIndexedDBに保存され、公開サイトへアップロードされません。

## 分類とPDFの規格

`public/printlib.schema.json` が共通のJSON Schemaです。PDFへ `printlib.json` を添付し、生成後に別ライブラリのPDF.jsで読み戻して一致を確認します。版番号は `1.0.0`。未対応の版を勝手に変換しません。通常PDFの原本は別Blobとして保持し、変更は派生PDFに保存します。

外部AIが返した「確定」「ユーザー確認済み」「OCRで検証済み」の自己申告は採用しません。引用を実際の抽出文字と照合し、辞書・親分類・複数教科・シリーズ順の矛盾を検証します。外部AIの画像読み取りだけでは自動確定しません。内容から数学Ⅲと数学演習、英語Ⅰ・Ⅱ・Ⅲを決める処理はありません。

承認済み辞書の明示ラベルと印刷教科名の直接一致を自動確定の対象とします。文字列の類似や、外部環境で取得した同一モデルの埋め込みベクトルの類似は候補提示に限定します。未知の明示ラベルは数を制限した仮辞書項目として利用できます。

## 非公開GitHub保存

[設定手順と制限](docs/sync-setup.md) を参照してください。GitHubトークンは同期APIの環境変数にのみ保存します。フロントエンドの同期キーはメモリだけに保持します。接続先が公開リポジトリなら拒否します。

外部サービスとの実同期、Android実機、OCR精度、大量PDFでの実機性能は未検証です。教科の自動確定精度99%以上という開発目標は、合成テストだけでは達成を主張できません。[実装・検証状況](docs/implementation-status.md) に確認範囲を記載しています。
